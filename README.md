# MAX Lite

Неофициальный клиент для мессенджера MAX (OneMe) на iOS.

## Возможности

- **Чаты и группы** — диалоги, групповые чаты, каналы
- **Сообщения** — текст, фото, видео, стикеры, голосовые, геолокация
- **Поиск** — по истории сообщений
- **Опросы** — создание и голосование
- **Настройки** — тёмная тема, размер текста, режим невидимки

## Требования

- iOS 17.0+
- Swift 5.0

## Сборка

### GitHub Actions (автоматически)

1. Перейди во вкладку **Actions**
2. Запусти workflow **Build unsigned IPA**
3. Скачай артефакт `MaxLite-unsigned-ipa`

Неподписанная IPA устанавливается через **AltStore**, **Sideloadly** или **TrollStore**.

### Локально (Xcode)

```bash
git clone https://github.com/n80406763-tech/MAXLITE.git
cd MAXLITE
open MaxLite.xcodeproj
```

Выбери схему **MaxLite** → Run (⌘R).

## Протокол

MAX работает через WebSocket (`wss://ws-api.oneme.ru/websocket`). Опкоды для звонков, архивации и некоторых функций администрирования групп не реализованы — вместо них приложение честно возвращает ошибку `UnsupportedFeature`.
